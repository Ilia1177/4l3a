description: Save progress and commit completed work
---

1. Run `make check -C pi-server`. Fix all failures.
2. Update `pi-server/docs/PROGRESS.md`.
3. Update `pi-server/docs/DECISIONS.md` if an architectural decision was made.
4. Inspect `git diff` and `git status`.
5. Stage only files belonging to the current task.
6. Create a conventional commit.
7. Verify with `git log -1 --oneline` and `git status`.
8. Never push.
